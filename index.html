便利なツール・拡張機能を配布しています

ovice Reaction Deck

oviceでオリジナルリアクションを自由に使えるChrome拡張機能。カスタム画像をパネルに並べてワンクリックで送信できます。

ダウンロード
インストール手順
  1. 上の「ダウンロード」ボタンからZIPファイルをダウンロードし、ダブルクリックして展開する
  2. 展開してできた ovice-reaction-deck フォルダを、デスクトップや書類フォルダなど、わかりやすい場所に移動する
  3. Chromeの右上「︙」メニュー →「拡張機能」→「拡張機能を管理」を開く
  4. 画面右上の「デベロッパーモード」のスイッチをONにする
  5. 「パッケージ化されていない拡張機能を読み込む」をクリックし、移動した ovice-reaction-deck フォルダを選択する
  6. Chromeのアドレスバーの右あたりに「う」のアイコンが表示されたら完了！
※ このフォルダを削除したり別の場所に移動すると拡張機能が動かなくなります。一度置いた場所から動かさないでください。
使い方
  1. まずChromeのアドレスバー右あたりの「う」アイコンをクリックして設定画面を開き、リアクション画像を追加する（初回は何も登録されていません）
  2. oviceを開く
  3. 画面右下に表示される ボタンをクリック
  4. リアクションパネルが開く
  5. 好きなリアクションをクリックすると発動！
設定・カスタマイズ

Chromeのアドレスバー右あたりの「う」アイコンをクリックすると設定画面が開きます。

リアクション画像の追加

  1. 「+ 画像を追加」ボタンをクリック
  2. 使いたい画像ファイル（PNG / GIF / WebP / JPEG）を選択
  3. 追加された画像の名前を編集できます

リアクション画像の管理

  • 各リアクションの名前はクリックして編集可能
  • 「A→Z」ボタンで名前順にソート
  • 「削除」ボタンで不要なリアクションを削除

パネル設定

  • 行数・列数 … パネルに表示するリアクションの並び（何行 x 何列）を調整
  • 透明度 … パネルの背景の透明度を変更
  • デフォルト音 … 新しく画像を追加したときに自動で設定される効果音を選択
  • 効果音の一括変更 … すべてのリアクションの効果音をまとめて変更

バックアップ

  • エクスポート … 登録したリアクションと設定をファイルに書き出し（バックアップ用）
  • インポート … エクスポートしたファイルから復元
更新手順
  1. 上の「ダウンロード」ボタンから新しいZIPファイルをダウンロードし、ダブルクリックして展開する
  2. 展開してできたフォルダの中身で、既存の ovice-reaction-deck フォルダの中身を上書きする（フォルダごと置き換えてもOK。同じ場所に置いてください）
  3. Chromeの右上「︙」メニュー →「拡張機能」→「拡張機能を管理」を開き、ovice Reaction Deck の更新ボタン（丸い矢印）をクリック
  4. oviceのタブをリロードすれば更新完了
登録済みのリアクションや設定はそのまま残ります。
注意事項
  • ovice-reaction-deck フォルダを削除・移動すると拡張機能が動かなくなります。場所を変えないでください
  • Chromeを更新した際に「この拡張機能は無効化されました」と表示されることがあります。その場合は拡張機能の管理画面で再度有効にしてください
