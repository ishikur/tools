便利なツール・拡張機能を配布しています

ovice Reaction Deck

oviceでオリジナルリアクションを自由に使えるChrome拡張機能。カスタム画像をパネルに並べてワンクリックで送信できます。

  • 好きな画像をリアクションとして登録できる
  • ovice画面上のパネルからワンクリックで送信
  • パネルのサイズや透明度を自由に調整（コーナーをドラッグして拡大縮小も可能）
  • リアクションの並び順をドラッグ&ドロップで入れ替え
  • リアクションごとに効果音を設定可能
  • 設定のエクスポート・インポートに対応

ovice の操作を便利にする機能

  • スペース入室時にリアクションパネルを自動で開く
  • 「ブラウザでの利用を継続」ダイアログを自動で閉じる
  • GIFアニメの表示切替（常時アニメーション / ホバー時のみ再生）

インストール手順（初回のみ）
📌 この手順は初めてインストールする時だけ実行してください。
すでにインストール済みでバージョンアップする場合は、下の「バージョンアップ手順」を見てください。
この手順を繰り返すと、同じ拡張機能が2つできてしまい、リアクション画像や設定が引き継がれなくなります。
  1. 上の「ダウンロード」ボタンからZIPファイルをダウンロードし、ダブルクリックして展開する
  2. 展開してできた ovice-reaction-deck フォルダを、デスクトップや書類フォルダなど、わかりやすい場所に移動する
  3. Chromeの右上「︙」メニュー →「拡張機能」→「拡張機能を管理」を開く
  4. 画面右上の「デベロッパーモード」のスイッチをONにする
  5. 「パッケージ化されていない拡張機能を読み込む」をクリックし、移動した ovice-reaction-deck フォルダを選択する
  6. Chromeのアドレスバーの右あたりに「う」のアイコンが表示されたら完了！
※ このフォルダを削除したり別の場所に移動すると拡張機能が動かなくなります。一度置いた場所から動かさないでください。
バージョンアップ手順（2回目以降）
  1. 上の「ダウンロード」ボタンから新しいZIPファイルをダウンロードし、ダブルクリックして展開する
  2. 展開してできた新しいフォルダの中のファイルを、すでに使っている ovice-reaction-deck フォルダの中に上書きコピーする（フォルダ自体は新規作成せず、既存フォルダの中身だけ差し替える）
  3. Chromeの右上「︙」メニュー →「拡張機能」→「拡張機能を管理」を開き、ovice Reaction Deck の更新ボタン（丸い矢印）をクリック
  4. oviceのタブをリロードすれば更新完了
登録済みのリアクションや設定はそのまま残ります。
⚠️ 「パッケージ化されていない拡張機能を読み込む」を新しいフォルダで再度実行しないでください。
同じ拡張機能が2つインストールされた状態になり、リアクション画像や設定が新しい方に引き継がれません（ChromeはフォルダのパスでIDを管理しているため、別物として扱われます）。

もし2つできてしまった場合の直し方：
  1. chrome://extensions/ を開き、新しく追加された方の「削除」をクリック（古い方にリアクション画像や設定が残っています）
  2. 残った古い方の「ファイルパスを表示」または「フォルダを開く」で、フォルダの場所を確認
  3. 新しいZIPの中身を、そのフォルダに上書きコピー
  4. chrome://extensions/ に戻り、ovice Reaction Deck の更新ボタン（丸い矢印）をクリック
  5. バージョンが新しくなっていれば完了。リアクション画像や設定もそのまま残ります
使い方
  1. oviceのスペースに入る
  2. 画面右下の ボタンをクリックしてリアクションパネルを開く
  3. 好きなリアクションをクリックすると発動！
初回はリアクション画像が登録されていません。下の「設定・カスタマイズ」から画像を追加してください。
設定・カスタマイズ

Chromeのアドレスバー右にある拡張機能アイコン（パズルピースの形 🧩）をクリックし、「ovice Reaction Deck」を選択すると設定画面が開きます。

💡 よく使う場合は、拡張機能メニューの「ovice Reaction Deck」の横にあるピン📌アイコンをクリックすると、アドレスバーの横に常時表示されて便利です。

リアクション画像の追加

  1. 「+ 画像を追加」ボタンをクリック、または画像ファイルをドラッグ＆ドロップ
  2. 対応形式：PNG / GIF / WebP / JPEG（複数選択可）
  3. パネル上に直接ドロップして追加することもできます
  4. 追加された画像の名前を編集できます

リアクション画像の管理

  • 各リアクションの名前はクリックして編集可能
  • 「A→Z」ボタンで名前順にソート
  • 「削除」ボタンで不要なリアクションを削除（パネル上では右クリックでも削除可能）
  • パネル上でドラッグ&ドロップして並び順を入れ替え

パネル設定

  • 行数・列数 … パネルに表示するリアクションの並び（何行 x 何列）を調整
  • 透明度 … パネルの背景の透明度を変更
  • GIF … 「常時アニメーション」をONにするとGIFが常に動きます。OFFの場合はホバー時のみ再生
  • デフォルト音 … 新しく画像を追加したときに自動で設定される効果音を選択
  • 効果音の一括変更 … すべてのリアクションの効果音をまとめて変更

バックアップ

  • エクスポート … 登録したリアクションと設定をファイルに書き出し（バックアップ用）
  • インポート … エクスポートしたファイルから復元
注意事項
  • Chromeを更新した際に「この拡張機能は無効化されました」と表示されることがあります。その場合は拡張機能の管理画面で再度有効にしてください
